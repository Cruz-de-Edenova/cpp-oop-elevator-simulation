# Priprema simulatora

> **Status:** Ova cjelina je u izradi.

Ova cjelina služi kao priprema za kasniju izradu simulatora lifta. Prije početka objektno-orijentiranog modeliranja definira se fizički sustav koji se simulira, te granica između fizičkog modela i upravljačkog programa.

## 01 - Opis lifta

Ova tema sadrži opis konstrukcije i načina rada hidraulične podizne platforme **Autoquip Titan Scissors Lift** koja će poslužiti kao osnova simulatora. Opisani su: odabrani model platforme, osnovna struktura sustava, električni i hidraulični sustav, način rada podizanja i spuštanja platforme, te sigurnosni i zaštitni elementi. Ovdje se opisuje sam lift i njegov način rada, dok će programski dio simulatora biti obrađen zasebno.
