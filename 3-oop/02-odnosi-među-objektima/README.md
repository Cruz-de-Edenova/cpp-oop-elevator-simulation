# Odnosi među objektima

Druga cjelina obrađuje kompoziciju, agregaciju i asocijaciju kao osnovne odnose među objektima, a završava praktičnim zadacima.

## Sadržaj

**02-01 — Kompozicija**
- Prikazuje kako objekt jedne klase sadrži objekte druge klase kao podatkovne članove, pri čemu je njihov životni vijek vezan uz objekt koji ih sadrži.

**02-02 — Agregacija**
- Objašnjava kako objekt jedne klase može okupljati objekte druge klase koji imaju neovisan životni vijek.

**02-03 — Asocijacija**
- Prikazuje povezanost i suradnju objekata različitih klasa bez odnosa vlasništva.

**02-04 — Zadaci**
- Donosi praktične zadatke za primjenu obrađenih odnosa među objektima u manjim C++17 programima.
