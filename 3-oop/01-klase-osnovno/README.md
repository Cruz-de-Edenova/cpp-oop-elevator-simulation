# Osnove klasa i objekata

Ova cjelina uvodi osnovne pojmove objektno-orijentiranog programiranja i njihovu primjenu u C++17. Sastoji se od osam tema (01-01 do 01-08) i završne teme s praktičnim zadacima (01-09).

## Sadržaj

| Tema | Naziv | Kratki opis |
| --- | --- | --- |
| 01-01 | Objekt i klasa | Klasa, objekt, atributi, ponašanja te osnovna razlika između `class` i `struct` |
| 01-02 | Članska funkcija i pokazivač `this` | Deklaracija i definicija članskih funkcija, operator `::` i pokazivač `this` |
| 01-03 | Enkapsulacija i kontrola pristupa | Privatni članovi, javno sučelje i kontrolirana promjena stanja objekta |
| 01-04 | Konstruktor i inicijalizacija objekta | Inicijalizacija članova, preopterećeni i delegirajući konstruktori |
| 01-05 | Konstruktor kopije, pretvorbeni konstruktor i `explicit` | Kopiranje objekata, plitko i duboko kopiranje te kontrola implicitnih pretvorbi |
| 01-06 | Destruktor i životni vijek objekta | Stvaranje i uništavanje objekata, dinamička memorija i oslobađanje resursa |
| 01-07 | `const` članovi klase i `inline` funkcije | Konstantni podatkovni članovi, `const` članske funkcije i `inline` |
| 01-08 | `static` članovi klase | Zajednički podatkovni članovi i statičke članske funkcije |
| 01-09 | Zadaci | Samostalna primjena obrađenog gradiva kroz tri skupine zadataka |

## Zadaci (01-09)

| Zadatak | Varijante |
| --- | --- |
| Senzor tlaka | `1a`–`1d` |
| Evidencija paketa | `2a`–`2c` |
| Spremnik ADC uzoraka | `3a`–`3c` |

Svaka varijanta zadatka ima zaseban direktorij, vlastiti `README.md` s uputama i pripadajuće C++ rješenje.
