# Zadaci

Tema 01-09 obuhvaća deset zadataka raspoređenih u tri skupine: senzor tlaka, evidenciju paketa i spremnik ADC uzoraka. Svaka sljedeća varijanta unutar skupine proširuje prethodno rješenje.

Svaki zadatak ima zaseban direktorij i vlastiti `README.md` s opisom zahtjeva i kratkim uputama za rješavanje. U istom direktoriju nalaze se i pripadajuće C++ datoteke s gotovim rješenjem zadatka.

## Sadržaj

| Direktorij | Opis zadatka |
| --- | --- |
| `1a_pressure_sensor` | Pohrana vrijednosti tlaka i prikaz njegova stanja prema zadanim pragovima |
| `1b_pressure_sensor` | Zadavanje vlastitih pragova tlaka pojedinom senzoru |
| `1c_pressure_sensor` | Provjera valjanosti pragova i njihova naknadna promjena uz usporedbu dvaju senzora |
| `1d_pressure_sensor` | Usporedba triju senzora tlaka i organizacija programa u više datoteka |
| `2a_package_counter` | Evidencija malih i velikih paketa na jednoj pokretnoj traci prema njihovoj visini |
| `2b_package_counter` | Odvojena evidencija i usporedba paketa na dvije trake s različitim graničnim visinama |
| `2c_package_counter` | Poništavanje evidencije i obrada dviju zasebnih serija paketa |
| `3a_sample_buffer` | Pohrana ograničenog broja uzoraka jednog simuliranog ADC kanala |
| `3b_sample_buffer` | Stvaranje neovisne kopije spremnika i zasebno dodavanje uzoraka u oba spremnika |
| `3c_sample_buffer` | Pohrana uzoraka više ADC kanala u jednom spremniku i GDB analiza životnog vijeka objekata |
