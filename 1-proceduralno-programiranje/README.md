# Proceduralno programiranje

Ova cjelina obuhvaća C++ temelje potrebne prije prelaska na objektno orijentirano programiranje. Gradivo je podijeljeno u četiri veće cjeline koje postupno uvode korisnički definirane tipove, funkcije i organizaciju programa, pokazivače, te reference.

## 01 - Razno

Obrađuje nekoliko osnovnih C++ konstrukcija koje će se kasnije često koristiti u OOP dijelu projekta: `struct`, alias deklaracije pomoću `typedef` i `using`, enumeracije, te `namespace` i `using` deklaracije.

## 02 - Razno2

Nastavlja pripremu za složenije C++ programe kroz `const` i `constexpr`, funkcije, prototipove i defaultne argumente, preopterećenje funkcija, te podjelu programa na `.h` i `.cpp` datoteke. Obrađuje se i zaštita datoteka zaglavlja, te kompajliranje i povezivanje programa podijeljenog u više datoteka.

## 03 - Pokazivači

Obrađuje osnove pokazivača, memorijske adrese i dereferenciranje, dinamičku alokaciju, dinamička polja i `std::vector`, pokazivače u radu s funkcijama, `const` pokazivače, te `void*`. Dio primjera koristi GDB za promatranje memorije, pokazivača i poziva funkcija.

## 04 - Reference

Obrađuje reference kao drugo ime postojećeg objekta, korištenje referenci s funkcijama, `const` reference, te razlike između referenci i pokazivača. Posebna pažnja posvećena je životnom vijeku objekata i pravilnom odabiru reference ili pokazivača kao parametra funkcije.
