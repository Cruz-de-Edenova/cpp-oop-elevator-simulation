# Tema 04 - Reference

> **Status:** U izradi

Tema 04 obrađuje reference u C++-u. Sastoji se od četiri podteme koje postupno uvode osnovno korištenje referenci, njihovu primjenu u funkcijama, odnos s `const` kvalifikatorom te usporedbu s pokazivačima.

## Sadržaj

1. **04-01 - Osnove referenci**  
   Deklaracija i inicijalizacija reference, pristup i promjena postojeće varijable pomoću reference, odnos varijable i reference te osnovna ograničenja referenci.

2. **04-02 - Reference i funkcije**  
   Korištenje referenci kao parametara funkcije i povratnih vrijednosti funkcije.

3. **04-03 - `const` i reference**  
   Reference na `const` objekte i korištenje `const` referenci u funkcijama.

4. **04-04 - Reference i pokazivači: razlike i ograničenja**  
   Usporedba referenci i pokazivača te situacije u kojima je potrebno koristiti pokazivač umjesto reference.
